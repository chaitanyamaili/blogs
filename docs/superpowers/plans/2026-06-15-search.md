# Search (Pagefind) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add full-text static search to the blog homepage using Pagefind, with results replacing the post list inline as the user types.

**Architecture:** Pagefind runs after `astro build` as a CLI post-step that crawls `dist/` and writes a search index into `dist/pagefind/`. At runtime, the Pagefind JS API is lazily imported from that generated bundle and queries the index in the browser — no server required. The search input lives on `index.astro`; when a query is active the Series and Posts sections are hidden and replaced with a styled results list.

**Tech Stack:** Pagefind (devDependency), Astro 4, Tailwind CSS, vanilla JS (client-side script via Astro `<script define:vars>`)

## Task 3: Add client-side Pagefind search script

**Files:**
- Modify: `src/pages/index.astro`

- [ ] **Step 1: Add the search script at the bottom of index.astro**

At the very end of `src/pages/index.astro`, before the closing `</BaseLayout>` tag, add:

```astro
<script define:vars={{ base: import.meta.env.BASE_URL }}>
  const input = document.getElementById('search-input');
  const resultsEl = document.getElementById('search-results');
  const emptyEl = document.getElementById('search-empty');
  const emptyQuery = document.getElementById('search-empty-query');
  const postList = document.getElementById('post-list');

  let pagefind = null;

  async function loadPagefind() {
    if (pagefind) return pagefind;
    try {
      // base ends with '/' e.g. '/blogs/'
      pagefind = await import(`${base}pagefind/pagefind.js`);
      await pagefind.options({ excerptLength: 20 });
    } catch {
      // pagefind index not available (e.g. during dev)
      pagefind = null;
    }
    return pagefind;
  }

  function showList() {
    postList.classList.remove('hidden');
    resultsEl.classList.add('hidden');
    emptyEl.classList.add('hidden');
    resultsEl.innerHTML = '';
  }

  function renderResult(result) {
    const url = result.url;
    const title = result.meta?.title ?? 'Untitled';
    const excerpt = result.excerpt ?? '';

    const card = document.createElement('a');
    card.href = url;
    card.className =
      'group block p-5 rounded-lg border border-border bg-card shadow-md hover:shadow-lg transition-shadow duration-300';
    card.innerHTML = `
      <h2 class="text-base font-semibold text-foreground group-hover:underline underline-offset-4 decoration-muted-foreground leading-snug mb-1.5">
        ${title}
      </h2>
      ${excerpt ? `<p class="text-sm text-muted-foreground leading-relaxed">${excerpt}</p>` : ''}
    `;
    return card;
  }

  input?.addEventListener('input', async (e) => {
    const query = e.target.value.trim();

    if (!query) {
      showList();
      return;
    }

    const pf = await loadPagefind();
    if (!pf) {
      // graceful degradation: keep showing the list if pagefind isn't available
      showList();
      return;
    }

    const search = await pf.search(query);
    const results = await Promise.all(search.results.map((r) => r.data()));

    postList.classList.add('hidden');
    resultsEl.innerHTML = '';

    if (results.length === 0) {
      resultsEl.classList.add('hidden');
      emptyEl.classList.remove('hidden');
      emptyQuery.textContent = query;
      return;
    }

    emptyEl.classList.add('hidden');
    resultsEl.classList.remove('hidden');
    results.forEach((r) => resultsEl.appendChild(renderResult(r)));
  });
</script>
```
