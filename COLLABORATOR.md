# Collaborating on This Blog

Thanks for your interest in contributing. This is a personal blog, so contributions are welcome in specific forms.

## What You Can Contribute

- **Typo / grammar fixes** — always welcome, just open a PR.
- **Technical corrections** — if something is factually wrong, open an issue with a reference.
- **Guest posts** — reach out first (see contact below) before writing anything.

## How to Contribute

1. Fork the repository.
2. Create a branch: `git checkout -b fix/your-description`.
3. Make your changes and commit with a clear message.
4. Open a pull request against `main` with a brief description of what changed and why.

## Content Guidelines

- Keep writing clear, direct, and jargon-light.
- Back technical claims with references or examples.
- No promotional or affiliate content.
- Posts must be original work — no AI-generated filler.

## Code Contributions

If you find a bug in the site itself (layout, build, accessibility):

- Open an issue describing the problem and the browser/OS you observed it on.
- PRs for straightforward fixes are welcome without a prior issue.

## Contact

For guest post proposals or anything that doesn't fit a GitHub issue, reach out via [chaitanyamaili.in](https://chaitanyamaili.in).

## Code of Conduct

Be respectful. Disagreements about technical content are fine; personal attacks are not. Contributions that violate this will be closed without comment.
